Roamr is a mockup social media app developed for a class project. 

Roamr is a social media app that is meant to share interesting and fun experiences about anything outdoors or nature related. 
They can be anything from hiking and rock climbing to fishing and kayaking. Not every experience needs to be as epic. 
It can also be as simple as walking your dog, a local fishing trip, bike rides, and much more. 

Original Contributors:
Cam Demarco, Brandon Martel, Kyle Shaw

How to run the project:
  - Create a fork
  - Install dependencies
    - npm install
  - Current expo SDK 50 is outdated so a custom development build for expo is needed: 
    - npx expo install expo-dev-client
    - npx expo run:android
